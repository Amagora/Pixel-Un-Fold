# Changelog - PaperFold v0.0.4

**Release Date:** Feature Iteration  
**Target Device:** Google Pixel Fold / Foldables  

### Added
- Independent **Reset to Default** buttons for both cover and inner wallpapers, allowing users to remove custom wallpapers and revert to default gradient backgrounds.
- High-contrast visual status indicators showing whether a custom wallpaper is currently active on each screen.

### Changed
- UI styling improvements to remove awkward white borders from image previews.
- Scoped dark borders to strictly contain the wallpaper image previews rather than wrapping outside controls.
