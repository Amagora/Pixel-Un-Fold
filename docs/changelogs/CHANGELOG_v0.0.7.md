# Changelog - PaperFold v0.0.7

**Release Date:** Theming & Aesthetics Polish  
**Target Device:** Google Pixel Fold / Foldables  

### Added
- Dynamic Material You (Monet) theme palette engine resolving dynamic accent colors from Android 12+ system wallpaper (`android.R.color.system_accent1_300`, etc.).
- Dedicated version badge in top app header.

### Changed
- Rebalanced preview card aspect ratios: Cover screen preview explicitly styled at 9:20 and Inner screen preview explicitly styled at ~1:1 square.
- Replaced awkward empty spaces with clean, structured action button rows and status badges.
