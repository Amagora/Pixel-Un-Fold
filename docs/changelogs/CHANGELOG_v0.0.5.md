# Changelog - PaperFold v0.0.5

**Release Date:** Feature Iteration  
**Target Device:** Google Pixel Fold / Foldables  

### Added
- **Appearance & Settings** bottom sheet dialog accessible via top-right gear icon.
- **AMOLED True Black Mode** toggle delivering `#000000` deep black surfaces for OLED battery savings.
- **Dark Theme** toggle allowing clean swapping between Light Mode and Dark Mode.
- Independent state preservation: Light mode does not erase or disable saved AMOLED mode preference.

### Changed
- Removed redundant toast notifications on setting changes to provide a cleaner, quieter user experience.
- Increased text contrast across all labels and description subtitles.
